# Aureon Intelligence

Aureon is a React + TypeScript intelligence workspace focused on premium AI workflows, visual creation, secure collaboration, and branded analysis experiences.

## Stack

- React 18
- TypeScript 5
- Vite 5
- Tailwind CSS
- shadcn/ui
- Lovable Cloud backend

## Local development

```sh
npm install
npm run dev
```

## Core areas

- AI and intelligence surfaces
- Secure user sessions and encrypted local board storage
- Whiteboard with infinite canvas, layers, live chart widgets, and imports
- Feature pages, dashboards, and branded landing experiences

## Security posture

- Authentication is handled through the integrated backend
- Board persistence is encrypted before local storage
- Production security headers are defined in `vercel.json`
- Sensitive backend credentials are kept out of client code

## Publishing

Use the project publish flow in Lovable to ship the latest build.
