asherin.sentinel

the desktop watch. runs without a browser tab, while this machine is awake.

open asherin.com → dashboard → asherin.sentinel → devices, and generate a code. it lasts ten minutes.

idle 0 waiting

honest boundary: this process records while the machine is awake and signed in. it cannot record while the machine is powered off, asleep, or hibernating — no user-space process on any operating system can. sleep gaps appear as gaps in the timeline. recording is never hidden: the tray icon stays visible and the operating system shows its own microphone indicator.
